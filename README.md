# seodraft skills

Agent skills that connect OpenSEO research to the seodraft MCP.

- `skills/seodraft-content`: turns OpenSEO keyword research, clusters, Search Console queries, AI answer research and audits into briefed, evidence-backed drafts in seodraft.

Needs the OpenSEO MCP and the seodraft MCP (https://seodraft.app/mcp) connected to your agent. MIT licensed.
